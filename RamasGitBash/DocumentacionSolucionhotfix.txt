EJERCICIO DE RAMAS EN GITHUB

RAMA HOTFIX/SOLUCION

1. CREACIÓN DE LA RAMA
Primero se creó la rama hotfix/solucion desde la rama master utilizando:

git checkout -b hotfix/solucion

Después se utilizó git branch para comprobar que la rama se creó correctamente.

2. CREACIÓN DEL ARCHIVO

Dentro de la carpeta RamasGitBash se creó el archivo DocumentacionSolucionhotfix.txt utilizando:

touch DocumentacionSolucionhotfix.txt

3. PUBLICACIÓN DEL ARCHIVO
Primero se agregó el archivo:

git add DocumentacionSolucionhotfix.txt

Después se realizó el commit:

git commit -m "Agrega documentación en rama hotfix"

Por último, se subió la rama a GitHub utilizando:

git push -u origin hotfix/solucion

4. SINCRONIZACIÓN
Al finalizar, se comprobó que la rama hotfix/solucion quedó creada tanto localmente como en GitHub y que los cambios se sincronizaron correctamente.
